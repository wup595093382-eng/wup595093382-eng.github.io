发布设置

第一次使用

  1. 创建仅限当前仓库的 GitHub Token。
  2. 在“Repository permissions”中把 Contents 设为 Read and write。
  3. 把令牌粘贴到左侧，然后开始编辑。
  4. 完成修改后点击“发布到公网”。

打开 GitHub Token 创建页面

编辑说明

常规字段可直接修改。图片和视频字段旁可选择本地文件替换，文件会自动上传到当前网站。

页面底部的“高级 JSON”可以增加或删除作品、分镜步骤和图片条目。

编辑作品集

所有改动先保存在本机草稿中。点击“预览修改”查看效果，确认后再发布到公网。
